## 2. 분석 방법론

### 2.1 Global-to-Local 접근법
```
Stage 1: 문항별 전체 데이터 분석
  └─ 모든 계열사 통합 (17,643명)
  └─ 마스터 토픽 프레임워크 구축

Stage 2: 계열사별 매칭
  └─ 24개 계열사 개별 분석
  └─ 마스터 토픽에 할당
```

### 2.2 텍스트 분석 기법

#### 2.2.1 한글 형태소 분석 (KoNLPy)
- **도구**: Okt (Open Korean Text)
- **목적**: 의미 있는 명사 추출
- **처리 과정**:
  ```python
  원문 → 형태소 분석 → 명사 추출 → 불용어 제거 → 핵심 키워드
  ```
- **장점**: 한국어 특성을 고려한 정확한 단어 분리

#### 2.2.2 TF-IDF (Term Frequency-Inverse Document Frequency)
- **목적**: 단어의 중요도 계산
- **원리**:
  - TF: 특정 문서 내 단어 빈도
  - IDF: 전체 문서에서의 희귀성
  - TF-IDF = TF × IDF (높을수록 중요)
- **활용**:
  - 문서-단어 행렬 생성
  - 각 응답의 벡터화
  - 키워드 중요도 순위 결정

#### 2.2.3 K-means 클러스터링
- **목적**: 유사한 응답끼리 그룹화
- **과정**:
  1. TF-IDF 벡터 공간에 응답 매핑
  2. K개 중심점 설정 (K=20~30)
  3. 가장 가까운 중심점으로 응답 할당
  4. 중심점 재계산 및 반복
- **결과**: 의미적으로 유사한 응답 군집

### 2.3 주제명 생성 방법

#### 2.3.1 키워드 기반 자동 생성
- **1차**: 클러스터별 상위 3개 키워드 추출
- **2차**: 도메인 템플릿 매칭
  ```
  예: ['전략', '달성', '목표'] → "목표 달성 의지 부족"
  ```

#### 2.3.2 LLM 활용 정제 (실행 완료)
- **목적**: 더 자연스럽고 의미 있는 주제명 생성
- **활용 LLM**: Claude (Anthropic)를 통한 주제명 개선
- **실행 내용**:
  - 키워드와 샘플 응답을 참조하여 의미 있는 주제명 생성
  - 중복 주제명 해결 (번호 추가)
  - 문맥에 맞는 구체적 표현으로 개선
- **개선 예시**:
  ```
  Before: "공감/성장" → After: "VALUE-UP 필요성 공감 부족"
  Before: "조직/업무" → After: "과도한 보고 체계"
  Before: "전략/달성" → After: "목표 달성 의지 부족"
  ```
