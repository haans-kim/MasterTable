# CJ그룹 컬처서베이 주관식 문항 분석 실행 계획

## 📊 분석 현황

### 완료된 작업
1. **기초 분석 시스템 구축** (`culture_survey_analysis.py`)
   - 기본적인 텍스트 처리 및 빈도 분석
   - 계열사별 응답 분류
   - 결과: `culture_survey_report_20250929_122007.xlsx`

2. **고도화 분석 시스템 구축** (`advanced_analysis.py`)
   - TF-IDF 기반 키워드 추출
   - K-means 클러스터링
   - 카테고리별 자동 분류
   - 결과: `advanced_culture_report_20250929_122525.xlsx`

### 주요 발견사항
- **전체 응답**: 17,643명 (24개 계열사)
- **주요 이슈 카테고리**:
  - 업무프로세스 개선 필요 (가장 빈번)
  - 전략/비전 명확화 요구
  - 조직문화 개선

## 🎯 향후 실행 계획

### Phase 1: 데이터 품질 개선 (1-2일)
1. **한글 형태소 분석 적용**
   ```bash
   pip install konlpy jpype1-py3
   ```
   - 더 정확한 키워드 추출
   - 동의어/유사어 처리

2. **텍스트 전처리 강화**
   - 특수문자 및 이모지 처리
   - 줄임말/은어 정규화
   - 중복 응답 제거

### Phase 2: LLM 기반 심화 분석 (2-3일)
1. **OpenAI API 또는 Claude API 활용**
   ```python
   # 예시 구조
   def llm_topic_extraction(responses, question_context):
       prompt = f"""
       다음은 '{question_context}'에 대한 직원들의 응답입니다.
       주요 토픽 5-10개를 추출하고, 각 토픽의 핵심 메시지를 요약하세요.

       응답들: {responses[:20]}  # 샘플링

       형식:
       1. 토픽명: 핵심 메시지
       2. ...
       """
       return llm_api_call(prompt)
   ```

2. **감성 분석 고도화**
   - 긍정/부정/중립 분류
   - 강도 측정 (매우 부정 ~ 매우 긍정)

3. **계열사별 맞춤 인사이트**
   - 업종별 특성 반영
   - 규모별 차이 분석

### Phase 3: 실시간 분석 시스템 구축 (3-5일)
1. **웹 대시보드 개발**
   ```python

       show_company_analysis(company)
   ```

2. **대화형 분석 기능**
   - 자연어 질의응답
   - 동적 필터링
   - 실시간 비교 분석

### Phase 4: 자동화 파이프라인 (5-7일)
1. **배치 처리 시스템**
   ```python
   class AutomatedAnalysisPipeline:
       def __init__(self):
           self.stages = [
               DataLoadStage(),
               PreprocessingStage(),
               GlobalAnalysisStage(),
               CompanyAnalysisStage(),
               ReportGenerationStage()
           ]

       def run(self, config):
           for stage in self.stages:
               stage.execute(config)
   ```

2. **스케줄링 및 알림**
   - 정기 분석 자동 실행
   - 이상 패턴 감지 시 알림
